PromptVault Privacy Policy

Last updated: May 3, 2026

PromptVault is designed as a private, local-first prompt manager. The free version does not create an account, send analytics, use telemetry, or make network requests.

What PromptVault Stores

PromptVault stores your prompts, tags, local usage counts, selected text you choose to save, and settings in Chrome storage on this browser using chrome.storage.local. PromptVault may keep legacy folder IDs for compatibility with older local prompt records, but folders are not shared or transmitted.

What PromptVault Does Not Collect

PromptVault does not collect, sell, share, transmit, or remotely process your prompts, selected text, or browsing data. There are no third-party analytics scripts and no external scripts.

Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Permissions

PromptVault requests storage for your local library, contextMenus so selected text can be saved, and host permissions limited to supported AI chat websites so statically declared content scripts can show the in-chat launcher, support /pv, and inject selected prompts into supported chat fields.

Contact

For privacy questions, contact the extension publisher listed in the Chrome Web Store listing.
